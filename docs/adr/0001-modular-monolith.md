# ADR-0001. Modular monolith вместо микросервисов

**Статус:** принято · **Дата:** 2026-08-22

## Контекст

MVP обслуживает мебельные магазины Ташкента. Ожидаемая нагрузка на старте —
десятки компаний, единицы сообщений в секунду. Команда маленькая, скорость
вывода функциональности критична.

## Решение

Один деплой-артефакт API с жёсткими границами модулей внутри
(`auth`, `products`, `leads`, `conversations`, `ai`, `channels`).
Кросс-модульное взаимодействие — только через публичные сервисы модуля.

## Последствия

**Плюсы:** одна транзакционная граница (лид и сообщение пишутся согласованно),
один деплой, простая локальная разработка, отсутствие распределённых сбоев.

**Минусы:** общий процесс — общий отказ; масштабирование только целиком.

**Смягчение:** границы модулей соблюдаются правилами импорта и ревью, поэтому
выделение любого модуля в сервис остаётся механической операцией.
