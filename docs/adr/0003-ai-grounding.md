# ADR-0003. Заземление AI через инструменты, а не через контекст

**Статус:** принято · **Дата:** 2026-08-22

## Контекст

Главный риск продукта — выдуманные товары, цены и обещания. Один неверный
ответ про цену дороже, чем десять «я уточню у менеджера».

## Решение

Каталог **не** попадает в промпт целиком. Все факты модель получает только
вызовом инструментов (`search_products`, `get_product`, `get_company_info`),
результаты которых формируются из БД компании. В system prompt — жёсткий запрет
называть данные, которых нет в результатах инструментов, и предписание честно
сообщать об отсутствии информации.

Квалификация лида считается кодом (детерминированный скоринг), а не моделью.

## Последствия

**Плюсы:** цена в ответе всегда из БД; каталог любого размера; стоимость
промпта не растёт с числом товаров; поведение проверяемо тестами с фейковым
клиентом Claude.

**Минусы:** больше обращений к модели (цикл tool-use), выше задержка ответа.

**Смягчение:** лимит итераций, компактные результаты инструментов (до 8 товаров,
только значимые поля), окно истории вместо полной переписки.
