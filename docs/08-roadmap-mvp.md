# 08. Дорожная карта MVP

Критерий готовности всего MVP: **реальный мебельный магазин подключает
Telegram-бота, загружает каталог и получает первого квалифицированного лида
без участия менеджера.**

## Модуль 0 — Фундамент

- Монорепозиторий, TypeScript, ESLint, Vitest.
- Конфиг с Zod-валидацией окружения (падаем на старте, а не в рантайме).
- Ядро: ошибки, конверт ответа, логгер, requestId, обработчик ошибок.
- Prisma schema + guard-расширение мультиарендности.

**Готово, когда:** `npm run verify` зелёный, `/health` отвечает.

## Модуль 1 — Аутентификация и арендаторы

- Регистрация компании + владельца одной транзакцией.
- Вход, refresh с ротацией, logout, `/auth/me`.
- Middleware `authenticate` и `requireRole`.
- Сотрудники: CRUD, правила ролей.

**Готово, когда:** тесты подтверждают, что компания A не видит данные компании B.

## Модуль 2 — Каталог

- CRUD товаров, пагинация, фильтры, категории.
- Импорт CSV с идемпотентностью по `external_id` и отчётом об ошибках строк.
- Поисковый запрос, который позже используется AI-инструментом.

**Готово, когда:** «диван до 8 млн» находит корректный набор товаров.

## Модуль 3 — База знаний

- KnowledgeBase (о компании, адрес, график, доставка, оплата, гарантия,
  инструкции менеджеру), FAQ CRUD, AI-настройки.

**Готово, когда:** сборка system prompt из реальных данных проходит тест.

## Модуль 4 — AI-агент

- Определение языка, PromptBuilder, OpenAiLlmClient, ToolExecutor, 7 инструментов.
- Скоринг и автоквалификация лида.
- Деградация при недоступности AI.

**Готово, когда:** прогон сценария «Мне нужен диван до 8 млн» на моке модели
даёт: уточняющий вопрос → показ товаров → запрос контакта → лид `QUALIFIED`.

## Модуль 5 — Telegram

- Подключение бота, шифрование токена, setWebhook.
- Webhook с проверкой секрета, идемпотентность, фоновая обработка.
- Текст, фото, голос, contact.
- Карточки товаров, кнопка отправки номера, передача менеджеру.

**Готово, когда:** интеграционный тест проходит путь от `update` до созданного лида.

## Модуль 6 — CRM

- Лиды: список, фильтры, карточка, переходы статусов, назначение менеджера,
  история событий.
- Диалоги: инбокс, история, ответ менеджера, takeover/release/close.

**Готово, когда:** менеджер может перехватить диалог и довести лид до `WON`.

## Модуль 7 — Админ-панель (Nuxt)

- Вход, дашборд с метриками, лиды, диалоги, каталог, база знаний, сотрудники,
  настройки AI и каналов.

**Готово, когда:** весь путь владельца магазина проходится в браузере.

## Модуль 8 — Эксплуатация

- Dockerfile для API и web, docker-compose с Postgres, конфиг Nginx, PM2.
- Сид демо-данных, README с инструкцией запуска.

**Готово, когда:** развёртывание на чистой Ubuntu VPS по инструкции.

## После MVP (не входит)

Голосовая транскрипция, Instagram/WhatsApp, биллинг, RAG по документам,
автоответы по расписанию, A/B промптов, экспорт в внешние CRM.
